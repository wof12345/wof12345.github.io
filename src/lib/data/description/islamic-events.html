Islamic Events is a platform for a community organisation that runs learning sessions, Qur'an recitation events, and charity drives. People browse what's coming up, register, and pay if the event has a fee. The organisers run it all from one admin area.

It's a single Next.js App Router project on Prisma and PostgreSQL, with NextAuth for email and Google sign-in and next-intl serving every page in English and Bangla. Events belong to categories and carry tags, images, a date, a location, an optional capacity, and a draft or published status.

No two events ask the same questions, so the registration form is data, not code.

Forms defined per event

A lecture might need only a name and phone number, while a sponsored iftar needs dietary details and a guest count. Instead of hard-coding fields, each event can have a form schema stored as JSON next to it. A shared dynamic form component renders that schema on the registration page, and the answers are saved as JSON on the registration. Adding a new kind of event therefore needs no migration and no deploy.

Fees without forcing payment

Most events are free. Those that aren't can have a fixed fee or let people choose an amount, and a registration with a fee gets its own payment record in BDT with a status, a gateway reference, and a history of what the gateway reported. Keeping payments separate from registrations means a free event never touches the payment code at all.
