Preorder Manager is a small admin for preorder campaigns, with two screens: a list and a form. The point was to do both of them properly.

The list can be filtered by status, sorted by name or any of its dates in either direction, and paginated, and all of that runs on the server against the database rather than in the browser. The filter state lives in the URL, so a filtered view can be refreshed or shared. Rows can be selected, switched between active and inactive in place, or deleted. Creating and editing share one form with inline validation, a saving state, and toast messages.

Server Actions all the way down

There's no separate API. Create, update, toggle, and delete are Next.js Server Actions, and their input and the page's query parameters are checked with Zod schemas before anything reaches the database. Out-of-range page numbers and unknown sort keys are clamped to sensible defaults instead of failing. Prisma talks to SQLite through the libSQL adapter, so the same code runs on a local file or on Turso.

At a glance

  • — Server-side filter, sort, and paging
  • — Zod-validated Server Actions
  • — One form for create and edit
  • — libSQL, local or Turso
