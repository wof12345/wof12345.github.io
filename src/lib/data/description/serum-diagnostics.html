Serum Diagnostics runs the day-to-day of a diagnostic centre, from a patient's first test order to the printed report, and gets results from the lab machines without anyone retyping them.

The application is a CodeIgniter system on MySQL. It covers new diagnoses and patient records, lab reporting and report delivery, due collection, purchases and expenses, financial reports, doctor and marketing-area commissions, and licensing. Reports are rendered to PDF with mPDF, with QR codes so a printed report can be checked.

Every analyser speaks a slightly different dialect of a standard.

Talking to the analysers

Each lab machine gets its own long-running PHP listener on a TCP port. The Maglumi 800 immunoassay analyser uses ASTM E1394, so its listener handles the ENQ/ACK handshake, reads framed records between STX and ETX, and parses header, patient, order, and result records. The CXL Pro T240 Plus chemistry analyser uses HL7 over MLLP. Its listener acknowledges each message, answers the machine's order queries for a sample, and then inserts or updates each result against the right test. Other listeners cover a urine analyser and a Selectra chemistry analyser. Every exchange is logged, so when a machine and the system disagree there's a record of what was actually sent.
