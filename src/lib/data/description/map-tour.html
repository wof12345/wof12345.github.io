Waive is a map-first way to find what's happening nearby: events, food, offers, and services, listed next to a map that shows where each one is.

Each tab loads a list of places with a date filter, and every item has a marker on an OpenLayers map, which can switch between OpenStreetMap and terrain base layers. Items can be liked, and the list animates as it filters and reorders. Turf.js handles the geometry, such as centring the map on a set of places. The content is generated with Faker, because the goal was the interaction between the list and the map rather than a real data source.
