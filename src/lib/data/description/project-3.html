A sleek, mobile-first weather application delivering hyper-local forecasts, air quality indices, and severe weather alerts powered by the OpenWeatherMap API.

Standout features:

  • Dynamic backgrounds that shift with the current condition — rain, sun, snow.
  • A 7-day forecast with temperature, humidity, and precipitation.
  • Air quality (AQI) and UV index reporting for outdoor planning.
  • Severe weather alert push notifications.

Designed for thumb-friendly navigation on small screens, scaling gracefully to desktop.
