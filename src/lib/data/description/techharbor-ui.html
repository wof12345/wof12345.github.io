TechHarbor UI is the starting point I built for new dashboards: a SvelteKit component kit, ready-made layouts, and a chat module wired to a real backend.

The kit covers the parts every admin panel ends up needing. Inputs include dropdowns, searchable and multi-select pills, date fields, text areas, and file and image uploads. There are also tabs, steppers, tables, context windows, a month-view calendar with events, typography, and nested section, container, and side-nav layouts. Every page under the dashboard shows the components in use, so the starter is its own documentation.

A backend to go with it

The kit pairs with a FastAPI service that I set up as a reusable base: SQLAlchemy models with Alembic migrations, JWT login and registration, and a chat module with chatrooms and members. Messages travel over a WebSocket per chatroom, and the socket is authenticated with the same token as the REST API. The SvelteKit side keeps the token in a cookie and calls the API from the server, so the browser never talks to the backend directly.
