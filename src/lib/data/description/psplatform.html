PSPlatform is a workspace for small organisations: one place for the team, its tasks, its conversations, and its paperwork.

An organisation signs up, invites people by link, and gets a kanban board, group and direct messaging, posts written in a block editor, invoices with line items, and shared files. A separate admin console oversees users, posts, messages, invoices, and files across the platform. It's built on SvelteKit and Supabase, using Supabase for auth, Postgres, storage, and realtime, and deployed to Cloudflare.

A team chat that the platform's own admins can't read.

End-to-end encrypted messages

Each user gets a NaCl key pair. The private key is itself encrypted with a secret before it is stored, so the database never holds it in the clear. When someone sends a message, the browser encrypts it separately for every participant's public key and stores one ciphertext per recipient. Each reader decrypts only their own copy. The server passes and stores messages it can't read.

Realtime without polling

The kanban board and the message list both subscribe to Supabase realtime channels, so a card moved by one teammate or a new message shows up for everyone else straight away.
